# X One Click Block

一个独立实现的 Chrome Manifest V3 扩展：在 X（Twitter）的推文、用户列表和个人主页旁加入一键拉黑或静音按钮，并提供批量队列、本地账本、统计与备份。

## 当前功能

- 在时间线、搜索、粉丝/关注列表、通知、话题、社群、互动列表和个人主页注入一键按钮
- 可选择默认执行“拉黑”或“静音”
- 自动驱动 X 官方菜单和确认框，不调用非公开 API
- 从文本、X 链接、CSV 或 JSON 导入批量账号
- 后台逐个打开个人主页处理队列；支持停止、重试失败项和运行历史
- 按当前登录的 `@handle` 分开保存拉黑/静音账本
- 搜索账本、导出完整 JSON 备份、选择性恢复和清理本地数据
- 数据仅保存在 `chrome.storage.local`

## 本地安装

1. 打开 `chrome://extensions`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本仓库目录
5. 打开或刷新 [X](https://x.com)

首次使用批量队列前，请确认浏览器已经登录 X。队列会创建不激活的临时标签页，完成每个账号后自动关闭。

## 开发与验证

项目不需要构建步骤，浏览器直接加载仓库即可。

```bash
node --test
find src -name '*.js' -exec node --check {} \;
```

## 实现说明

X 是持续变化的单页应用。扩展优先使用相对稳定的 `data-testid` 和 URL 结构识别页面元素，通过 `MutationObserver` 适配无限滚动和站内跳转。真正的拉黑/静音仍由 X 自己的界面执行，因此操作结果、频率限制和账号权限以 X 为准。

此项目独立实现公开描述的产品行为，不包含第三方扩展的源码、名称、图标或其他品牌素材。
